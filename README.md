## Choose the output first

- **Explore a layout idea:** start with a written brief and a concept image.
- **Revise an existing plan picture:** use an image-editing workflow; check that fixed features are preserved.
- **Move walls and furniture as objects:** choose a geometry or scene editor and inspect its export format.
- **Explore a room's appearance:** start with a room photograph and a style brief.

An image with dimension labels is not evidence of measured geometry. A 3D-style rendering is not necessarily an editable 3D scene. Review the output you actually receive before using it for a real project.

## A repeatable selection exercise

1. Prepare one brief and keep the measurements and fixed features unchanged.
2. Decide the required output: image, annotated drawing, schematic linework or editable project.
3. Inspect whether the result follows the room count, openings and arrangement you requested.
4. Check how a revision works and which actions consume credits.
5. Compare the cost of obtaining a usable result, including revisions and exports.
6. Retain real measurements and get qualified review for construction or permitting.

Example floor plan brief:

> Explore a two-bedroom home concept with an open kitchen and living area. Keep the entrance on the south side. Include storage near the hall and leave a clear route between bedrooms and the living space. Use my measured dimensions as requirements, and label the rooms.

Example room photo brief:

> Keep the existing window and doorway. Explore a warm minimal palette with a light sofa and compact storage. Preserve a clear route from the entrance to the window. Show a visual concept for discussion, rather than a measured fit-out drawing.

These are example input briefs, not sample test scores or proof that any model follows every instruction.
